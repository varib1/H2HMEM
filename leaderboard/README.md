# Leaderboard

This directory contains the submission template for the H2HMem leaderboard.

| File | Description |
|------|-------------|
| `prediction_template.txt` | JSON template defining the required submission format |

## Submission

To participate in the leaderboard:

1. Run inference on dyadic and multi-party datasets.
2. Format predictions according to `prediction_template.txt`.
3. Prepare two JSON files: `prediction_dyadic.json` and `prediction_multiparty.json`.
4. Submit at the [H2HMem Leaderboard](https://h2hmemleaderboard1.vercel.app/).

For details, see the main [README](../README.md#-leaderboard-submission).
